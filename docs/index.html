Key finding

Reward is a proxy—not the goal.

A reward function can encourage the wrong behaviour. The hover bonus earned a high modified score, yet the policy performed poorly when evaluated with the original reward.

Training signal

More training helped this run.

Continued PPO improved mean original reward by 122.42 points over the baseline on the same 20 evaluation seeds, and 8/20 episodes reached a reward of at least 200.

02 / Mission systems

How the agent learns.

PPO learns a policy by interacting with the environment, collecting rewards, and updating its behaviour over many steps.

🧠

Observe → act → learn

The environment supplies eight values about position, velocity, angle and landing-leg contact. The policy chooses one of four discrete engine actions each step.

🧪

Test the reward, too

Experiments added a time penalty or hover bonus. Evaluating with the original reward exposed a gap between optimising the score and completing the intended task.

📊

Compare on shared seeds

Using the same 20 episode seeds helps make the policy comparison more meaningful than testing each model on unrelated episodes.

🎮

Replay locally

The Python project includes Pygame viewers for the trained policy and a failure replay. The web animation is a visual showcase, not PPO running in the browser.

03 / Your launch checklist

Run the real agent locally.

Clone the repository to use the trained-policy scripts on your computer. The website itself needs no Python server after deployment.

  1. Get the project

    Clone the GitHub repository and open its folder in VS Code.

    git clone https://github.com/abhiii04-25/lunar-lander-rl.git
  2. Install requirements

    Use Python 3.11 and a virtual environment.

    py -3.11 -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
  3. Run a viewer

    Once the required model checkpoint exists locally, launch a Pygame replay.

    python 13_cinematic_lander.py

Model checkpoint files are not required for the static website. If a local viewer says a model file is missing, train the model first or obtain the checkpoint and put it in the path expected by that script.
